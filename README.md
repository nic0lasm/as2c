# AS2C Patrimoine

Site www.as2cpatrimoine.com (HTML statique, hébergé chez OVH).

- `www/` : le site. Tout envoi sur `main` qui touche `www/` est publié automatiquement sur OVH (voir `.github/workflows/deploy.yml`).
- `CLAUDE-NOTES.md` : structure du site et procédure de modification.
- `JOURNAL.md` : journal des modifications.
- `outils/` : sauvegarde et vérification.
